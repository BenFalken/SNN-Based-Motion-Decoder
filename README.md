# SNN Based Motion Decoder

## Data Preprocessing
Simply download data from drive and add to the repo in the "data" directory.

For example, Jenkins data ought to be located in:

$$\text{data} \rightarrow \text{Jenkins} \rightarrow \text{sub-Jenkins-ses-20090923-behavior+ecephys}$$

From there, the loaders will process the data.
